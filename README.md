#  Student Result Management System

##  Overview
The Student Result Management System is a Python-based project used to manage student records. It performs basic operations like adding, updating, deleting, and searching student details and marks.

This project helps in understanding CRUD operations and basic Python programming.

---

##  Features
- Add new student details  
- Update student information  
- Delete student records  
- Search student by ID or name  
- Display all student results  

---

##  Technologies Used
- Python  
- SQLite, SQL    
- VS Code
